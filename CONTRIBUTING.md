# Guia de Contribuição

Obrigado por considerar contribuir para o projeto **Normais Climatológicas Brasil**! 

## 🎯 Como Contribuir

### 1. Reportar Bugs

Se encontrar um bug, abra uma **Issue** com:
- **Título descritivo**
- **Descrição detalhada** do problema
- **Passos para reproduzir**
- **Resultado esperado vs real**
- **Seu ambiente** (Python version, OS, etc)

### 2. Sugerir Melhorias

Tem uma ideia? Abra uma **Discussion** ou **Issue** com:
- Descrição clara do problema
- Sua solução proposta
- Exemplos de casos de uso

### 3. Enviar Pull Request

#### Preparação

```bash
# 1. Faça um Fork do repositório
# 2. Clone seu fork
git clone https://github.com/SEU-USERNAME/normais-climatologicas-inmet-brasil.git

# 3. Crie uma branch
git checkout -b feature/sua-feature

# 4. Instale as dependências
pip install -r requirements.txt
pip install -r streamlit_requirements.txt

# 5. Faça suas mudanças
# 6. Teste seu código

# 7. Commit com mensagem clara
git commit -m "feat: descrição clara da mudança"

# 8. Push para sua branch
git push origin feature/sua-feature
```

#### Enviando o PR

1. Abra um Pull Request para a branch `main`
2. Descreva o que mudou e por quê
3. Referencie qualquer Issue relacionada (#123)
4. Aguarde revisão

### 4. Melhorar Documentação

Documentação está sempre melhorando! Você pode:
- Corrigir typos
- Adicionar exemplos
- Melhorar clareza
- Adicionar comentários no código

## 📋 Diretrizes

### Código

- ✅ Siga o padrão **Black** para formatação
- ✅ Adicione type hints
- ✅ Escreva docstrings claras
- ✅ Testes para novas features

### Commits

```
feat: nova funcionalidade
fix: correção de bug
docs: documentação
style: formatação
refactor: refatoração
test: testes
```

### Branches

```
feature/nome-da-feature
bugfix/nome-do-bug
docs/melhorias-docs
```
